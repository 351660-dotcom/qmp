# 03 · 功能清单 v0.1

> 按领域组织。标记说明：
> - ⚠️ = 合规硬约束
> - ❓ = 待确认决策点（详见 [05-待确认决策点.md](05-待确认决策点.md)）
> - 🔹 = 建议本期实现（AI 相关）
>
> 本清单待用户提供标杆系统资料后做 gap 对照，迭代为 v0.2。
>
> **交付标准**：每个功能项均须配套对应 API 接口与（如涉及外部）对接规范——见 ADR-011。

---

## 1. 平台运营中心（SaaS 运营方）
- 租户全生命周期：集团开户、套餐/版本（功能开关矩阵）、试用、续费、到期管控
- 平台计费：版本费 + 景区数 + 交易抽佣组合计费、平台账单
- 私有化交付管理：license 签发、版本分发、升级包、远程巡检
- 全局监控大盘、租户健康度、异常告警、工单客服

## 2. 租户·组织·权限
- 集团 → 景区 → 商户 → 门店/点位 四级组织
- 员工、角色、RBAC + 数据权限（按景区/商户/门店收敛）
- 商户入驻流水线：资质审核 → 存管进件 KYC → 电子签约 → 开通结算
- 全量操作审计日志

## 3. 商品中心
- **门票**：票种（成人/儿童/老人/学生/军人优待）、分时预约时段、提前购规则、有效期规则、实名规则（一票一证/一单多人）
- **套票/联票**：跨商户组合、子项独立核销策略、子项退改联动 —— 分账拆分源头
- **年卡/次卡**：开卡、激活、人脸绑定、有效期/次数、补卡
- **酒店**：房型、价格日历、连住规则、含早政策、取消政策
- **演出**：剧场座位图建模、票区/座位等级定价、场次
- **游船/游乐**：班次、舱位等级、安全限制（身高/年龄/健康声明）
- **餐饮零售**：菜品（规格/做法）、套餐券、代金券、零售 SKU/条码
- 商品上下架审核流

## 4. 库存中心（高并发核心）
- 五种库存模型（日期/场次/座位/房晚/SKU）统一管理、库存日历批量设置
- 渠道库存分配（OTA 切量、直营保留）、共享/独占库存
- 预占—确认—释放（下单锁定、超时回收）、超卖保护
- Redis 分桶扣减 + 异步落库（秒杀级抗压）

## 5. 价格中心
- 价格日历、渠道价、会员价、协议价（旅行社）
- 动态调价规则（早鸟、淡旺季）、改价审批流

## 6. 订单中心
- 跨商户混合购物车、统一下单、按商户拆单、订单状态机、超时关单
- 退改规则引擎（阶梯退费、部分退、改签/改期）
- 团队订单：旅行社批量下单、游客名单导入、导游带队凭证
- 电子发票（全电发票对接）

## 7. 支付与分账中心
- 聚合收银台：微信、支付宝（本期，见 ADR-015）；云闪付/数字人民币通过通道抽象层预留，后续接入
- 存管通道（通联/汇付类）：电子账簿、按订单项分账、多级抽佣、分账回退、商户提现
- 三方日对账（渠道账单/平台流水/分账明细）+ 差错处理工作台
- 现场收款：POS/扫码枪/付款码，统一并入对账体系

## 8. 核销中心
- 凭证：动态二维码、身份证、人脸、纸质票码
- 终端：闸机、PDA、商户小程序扫码、自助售取票机
- 核销规则：次数、时段、闸机分组（指定通道）、防重核
- **离线核销**：签名票码本地验签 + 边缘节点 + 断网续核 + 恢复对账
- 在园人数实时统计、⚠️ 最大承载量预警（文旅部对 A 级景区硬要求）

## 9. 酒店 PMS（自建 · 见 ADR-007）
- 房态图（实时房态/脏房/维修/锁房）、排房、散客/团队/钟点预订
- 前台：入住登记 ⚠️（对接公安旅业治安管理系统）、押金、换房、续住、退房结账
- 夜审、房费晚结、挂账
- 客房部：打扫任务、查房
- 门锁对接（多品牌制卡）；智能客控（电视/灯控）留二期（见 ADR-016）
- 房态价格向 OTA 直连同步；账务并入平台支付/分账体系

## 10. 餐饮零售收银（完整 · 见 ADR-008）
- 桌台管理：开台/并台/转台/预订
- 点单：顾客扫码点单、前台/店员代客下单（PDA/Pad）、加菜退菜、做法备注（本期仅此两种入口，见 ADR-017）
- 厨房：KDS 厨显/出票机、菜品沽清
- 结账：聚合支付、会员储值抵扣、折扣/赠菜权限、反结账审批
- 零售：扫码收银、简版进销存（入库/盘点/预警）
- 外卖平台（美团/饿了么）聚合接单：本期不做（见 ADR-017）

## 11. 会员与营销（集团级 · 见 ADR-009）
- 通会员：注册、等级成长值、积分获取/消耗、**跨商户积分核销费用分摊结算规则**
- ⚠️ 储值卡：单用途预付卡需商务部门备案，规则先确认
- 优惠券：满减/折扣/兑换，跨商户用券成本分摊
- 活动：秒杀、拼团、限时购、砍价
- 分销：分销员（导游/民宿主/达人）、二级佣金、提现
- 人群圈选 + 触达（短信、小程序订阅消息）

## 12. 渠道中心
- OTA 直连：携程、美团、抖音、飞猪 —— 产品映射、库存价格同步、订单回传、核销状态回传
- B2B 分销 API 开放平台：协议价、授信/预存余额、对账
- 政府「一码游」平台对接

## 13. 硬件接入平台
- 设备全生命周期：注册、鉴权、心跳、远程配置、固件 OTA、故障告警
- 多厂商闸机协议适配层；PDA、人脸终端、自助机、酒店自助入住机
- 景区边缘节点（本地服务器）：核销/设备管理本地自治 + 云端同步

## 14. 数据中台
- **指标语义层**（metrics layer）：统一口径、维度、血缘 —— AI 报表的底座（见 ADR-012）
- 实时大屏：客流、在园人数、营收、渠道占比
- 经营分析：集团/景区/商户/业态/渠道多维报表
- 财务：结算单、分账明细、佣金报表
- 客流预测、经营诊断

## 15. AI 能力中心（见 ADR-010 / ADR-012）
- **基础设施**：AI 网关（多模型接入、租户配额计费、敏感数据脱敏）、租户级 RAG 知识库、业务 API 的 MCP/tool-use Agent 接口层
- 🔹 **运营策略 AI**：经营诊断简报、策略建议、异常预警归因
- 🔹 **报表分析 AI**：ChatBI 自然语言查数、归因分析
- 🔹 **营销 AI**：活动策划助手、自然语言圈人群、文案/海报生成、活动自动复盘
- 🔹 **智能客服**：咨询 + 对接订单系统真正办理退改自助
- AI 行程规划、智能定价建议、AI 语音讲解导览（二期）

## 16. 开放平台（见 ADR-011）
- 开发者门户 + API 文档中心（OpenAPI）
- 应用注册、API Key / OAuth2、租户+应用级 scope 权限
- 限流配额、调用计量计费、调用审计
- Webhook 回调（订单/核销等事件，签名验签 + 重试）
- 沙箱环境、API 版本管理

## 17. C 端（微信小程序 + 支付宝小程序 + H5 · 见 ADR-006）
- 每租户独立小程序（微信 + 支付宝双平台，第三方代开发模式，见 ADR-013）
- 门户装修（每租户自定义首页/页面组件）
- 购票/订房/订座/点餐全流程、订单管理、退改自助
- 会员中心、卡包（年卡/优惠券）、积分
- 园内服务：手绘地图导览、设施排队信息（二期）
