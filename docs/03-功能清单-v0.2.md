## 本版（v0.2）变更摘要

对照票付通、智游宝、绿云、石基、哗啦啦、客如云、深大智能、别样红、趣买票 9 份标杆资料，相对 v0.1 新增/细化如下（编号对应下文章节）：

1. **订单中心**：新增「异常订单处理工作台」（重复下单、支付/出票失败、核销异常、退款异常的统一处理）
2. **核销中心**：核销凭证新增「腕带/手牌（RFID）」；新增防伪/活体检测规则；新增多码归一（政府码）适配说明
3. **酒店 PMS**：新增「单一客史」跨触点客户档案；新增基础会议室/宴会预订（见 ADR-020）；新增协议单位管理；新增移动管理端能力
4. **餐饮零售收银**：供应链数字化深化为总部-门店协同（见 ADR-019）；新增沽清管理；硬件清单补充电子菜单/标签打印/大屏叫号
5. **会员与营销**：新增「声誉/评价管理」（多渠道评价汇聚、差评预警闭环）；细化「全民营销」裂变与专业分销员的区分
6. **渠道中心**：新增政府码适配层（文旅一码通方向）；新增短视频平台导流获客链路
7. **硬件接入平台**：补充温泉/乐园腕带手牌读写设备、酒店电子房价牌、餐饮电子菜单/标签打印/大屏叫号设备
8. **数据中台**：新增客流热力图、闸机调度建议报表；餐饮成本/损耗分析（与 #4 对应）；同行竞品情报分析列为二期待评估
9. **AI 能力中心**：补充「智能核验防假票」「闸机调度建议」作为运营策略 AI 的落地场景示例
10. **开放平台**：新增「租户数据导出与迁移工具」，作为合规与客户信任的产品化能力
11. **C 端**：新增商城/特产购买（实物履约链路）、评价入口、园内二次消费钱包（腕带/手牌余额）
12. **新增 ADR**：ADR-019（餐饮供应链深度：总部-门店协同）、ADR-020（酒店基础会议室预订）、ADR-021（多租户「三不干涉」原则与数据自主权）

## 1. 平台运营中心（SaaS 运营方）
- 租户全生命周期：集团开户、套餐/版本（功能开关矩阵）、试用、续费、到期管控
- 平台计费：版本费 + 景区数 + 交易抽佣组合计费、平台账单
- 私有化交付管理：license 签发、版本分发、升级包、远程巡检
- 全局监控大盘、租户健康度、异常告警、工单客服
- 🆕 应急指挥/综合管控大屏（票付通「全域旅游」、深大智能「智慧景区」方向）：景区级客流、设备、舆情联动展示，作为政企项目可选交付物，二期按需建设

## 2. 租户·组织·权限
- 集团 → 景区 → 商户 → 门店/点位 四级组织
- 员工、角色、RBAC + 数据权限（按景区/商户/门店收敛）
- 商户入驻流水线：资质审核 → 存管进件 KYC → 电子签约 → 开通结算
- 全量操作审计日志
- 🆕「三不干涉」自治原则（智游宝公开定位：平台不干涉商户定价、资金流、客户数据）落地为系统约束——详见 ADR-021

## 3. 商品中心
- **门票**：票种（成人/儿童/老人/学生/军人优待）、分时预约时段、提前购规则、有效期规则、实名规则（一票一证/一单多人）
- 🆕 **套票/联票/组合产品**（2026-06-14 补充示例）：跨商户、**跨业态**组合销售，例如门票+游乐金（储值二次消费额度）、门票+零售商品（如门票+特产）、门票+酒店间夜、🆕 门票+停车（停车权益，见下方）。组合产品本身是独立 SKU，下单时按预设规则拆分为多个子项，各子项分别走自己的履约/核销链路（门票→核销中心，游乐金→第 17 节钱包余额充值，零售→商城履约，酒店→PMS 预订，停车→第 12 节第三方停车系统对接核销核对）；子项独立核销策略、子项退改联动，分账按子项实际价值拆分到对应商户 —— 分账拆分源头
- 🆕 **停车权益 SKU**（2026-06-14 补充，趣买票对标，轻量范围见 ADR-023）：按时长（如 2 小时免费/全天）或次数定义停车权益，可单独售卖或作为组合产品子项；实际计费与放行由第三方停车系统完成，平台侧仅记录权益核销结果
- 🆕 **年卡/次卡**（2026-06-14 细化）：
  - 卡种定义：有效期类型（自然年 / 购买后 N 天内 / 指定起止日期）与次数限制（不限次 / 总次数 N 次）自由组合，如「365 天内不限次」「100 次不限期」「1 年内 30 次」
  - 适用范围：可绑定单一 SKU、景区内多 SKU、或集团跨景区通用（跨景区年卡涉及集团内成本分摊，与第 11 节会员规则联动）
  - 使用规则：每日限用次数（如每天限入园 1 次）、是否需分时预约、节假日黑名单（不可用或需补差价）
  - 开卡/激活：实体卡/电子卡、人脸绑定防共享（1 卡 1 人）、补卡/挂失、到期续期
  - 核销联动：每次使用生成一条核销记录并扣减剩余次数（非终态，与第 8 节核销中心共用核验链路，区别于一次性门票的 TicketCredential 终态模型）
- **酒店**：房型、价格日历、连住规则、含早政策、取消政策
- **演出**：剧场座位图建模、票区/座位等级定价、场次
- **游船/游乐**：班次、舱位等级、安全限制（身高/年龄/健康声明）；🆕 温泉/水乐园二次消费账户（手牌/腕带余额，归入游乐业态，见第 8、13 节）
- **餐饮零售**：菜品（规格/做法）、套餐券、代金券、零售 SKU/条码
- 商品上下架审核流

## 4. 库存中心（高并发核心）
- 五种库存模型（日期/场次/座位/房晚/SKU）统一管理、库存日历批量设置
- 渠道库存分配（OTA 切量、直营保留）、共享/独占库存
- 🆕 集团内多景区资源池配置（2026-06-14 补充，智游宝对标）：库存可设为单景区独立池或集团级共享池（如集团通用年卡覆盖的多景区库位），与第 11 节跨商户/跨景区成本分摊联动
- 预占—确认—释放（下单锁定、超时回收）、超卖保护
- Redis 分桶扣减 + 异步落库（秒杀级抗压）

## 5. 价格中心
- 价格日历、渠道价、会员价、协议价（旅行社/企业协议单位）
- 动态调价规则（早鸟、淡旺季）、改价审批流
- 🆕 酒店电子房价牌联动（见第 13 节硬件清单，别样红对标）

## 6. 订单中心
- 跨商户混合购物车、统一下单、按商户拆单、订单状态机、超时关单
- 退改规则引擎（阶梯退费、部分退、改签/改期）
- 团队订单：旅行社批量下单、游客名单导入、导游带队凭证
- 电子发票（全电发票对接）
- 🆕 **异常订单处理工作台**（票付通、趣买票对标均强调）：重复下单识别与合并、支付失败/出票失败自动重试与人工介入、核销异常申诉处理、退款异常追踪，统一接入客服工单

## 7. 支付与分账中心
- 聚合收银台：微信、支付宝（本期，见 ADR-015）；云闪付/数字人民币通过通道抽象层预留，后续接入
- 存管通道（通联/汇付类）：电子账簿、按订单项分账、多级抽佣、分账回退、商户提现
- 三方日对账（渠道账单/平台流水/分账明细）+ 差错处理工作台
- 现场收款：POS/扫码枪/付款码，统一并入对账体系
- 🆕 资金安全边界遵循「三不干涉」原则（ADR-021）：平台经手资金仅在存管通道内流转，不挪用、不归集

## 8. 核销中心
- 凭证：动态二维码、身份证、人脸、纸质票码、🆕 腕带/手牌（RFID，温泉/水乐园/乐园二次消费场景，票付通对标）
- 终端：闸机、PDA、商户小程序扫码、自助售取票机
- 核销规则：次数、时段、闸机分组（指定通道）、防重核
- 🆕 防伪/活体检测规则（人脸核销防假票、防人情票，趣买票对标）
- **离线核销**：签名票码本地验签 + 边缘节点 + 断网续核 + 恢复对账
- 在园人数实时统计、⚠️ 最大承载量预警（文旅部对 A 级景区硬要求）
- 🆕 多码归一/政府码适配说明：在「一码游」对接（见第 12 节）基础上，核销凭证标准预留扩展点以兼容地方文旅平台的统一码标准（深大智能「文旅一码通」对标），具体接入范围按项目落地

## 9. 酒店 PMS（自建 · 见 ADR-007）
- 房态图（实时房态/脏房/维修/锁房）、排房、散客/团队/钟点预订
- 前台：入住登记 ⚠️（对接公安旅业治安管理系统）、押金、换房、续住、退房结账
- 夜审、房费晚结、挂账
- 客房部：打扫任务、查房
- 门锁对接（多品牌制卡）；智能客控（电视/灯控）留二期（见 ADR-016）
- 房态价格向 OTA 直连同步；账务并入平台支付/分账体系
- 🆕 **单一客史**：跨业态、跨触点客户档案（偏好、入住历史、消费记录），前台/餐饮/会员触点共享，与第 11 节集团级通会员打通（石基 Daylight 对标核心卖点）
- 🆕 **协议单位管理**：企业/旅行社协议单位档案，与第 5 节协议价联动（别样红对标）
- 🆕 **基础会议室预订**（见 ADR-020）：会议室/宴会厅资源建模、场地预订与下单，不含完整 MICE 报价审批流
- 🆕 **移动管理端**：管理者通过移动端远程审批、改价、调账/冲账、查看经营日报（别样红「微 PMS」对标），作为各管理后台的移动端形态而非独立模块
- 🆕 **客房送餐（Room Service）**（2026-06-14 补充，绿云 iCater 对标）：客房内点餐订单转入第 10 节餐饮系统下单/出餐，账单挂入房费（挂账机制复用 8 节挂账能力）

## 10. 餐饮零售收银（完整 · 见 ADR-008 / ADR-019）
- 桌台管理：开台/并台/转台/预订
- 🆕 顾客等位排队：小程序取号、叫号通知（2026-06-14 补充，客如云对标，高峰堂食场景）
- 点单：顾客扫码点单、前台/店员代客下单（PDA/Pad）、加菜退菜、做法备注（本期仅此两种入口，见 ADR-017）
- 厨房：KDS 厨显/出票机、🆕 菜品沽清（实时同步前厅与线上点餐入口，哗啦啦/客如云对标）
- 结账：聚合支付、会员储值抵扣、折扣/赠菜权限、反结账审批
- 🆕 **供应链数字化（总部-门店协同，见 ADR-019）**：总部统一采购计划、多仓库库存、门店订货与供应链中心接单、库存预警、损耗与成本核算、中央厨房加工配送对接；🆕（2026-06-14 补充，绿云 Materials Control 对标）细化为：多级采购审批、无纸化领料、POS 销售数据自动核减库存
- 外卖平台（美团/饿了么）聚合接单：本期不做（见 ADR-017）

## 11. 会员与营销（集团级 · 见 ADR-009）
- 通会员：注册、等级成长值、积分获取/消耗、**跨商户积分核销费用分摊结算规则**
- ⚠️ 储值卡：单用途预付卡需商务部门备案，规则先确认
- 🆕 **营销规则引擎**（2026-06-14 补充）：统一的促销规则配置中心，覆盖以下规则类型，可面向单商户、景区内多商户或集团跨景区配置：
  - 满减：订单满 X 元减 Y 元
  - 折扣：单品/订单按比例折扣，可限定商品范围/商户范围/时段
  - 买赠（买 A 送 B）：购买 A 商品赠送 B 商品，支持跨商户赠送（赠品成本按约定比例分摊给被赠商户，进入分账明细）
  - 消费送积分：按消费金额比例赠送集团通会员积分，与「跨商户积分核销费用分摊结算规则」统一
  - 赠券：消费/活动后发放优惠券（自家券或合作商户券）
  - 返现：消费后按比例退回会员钱包，需区分平台补贴 vs 商户自付（影响分账计算）
  - 规则叠加策略：会员价、优惠券、满减、折扣等是否可叠加需可配置（避免叠加导致价格异常）
  - 所有营销优惠在订单/分账明细中可追溯到承担方，与第 7 节分账中心、第 14 节财务报表打通
- 活动：秒杀、拼团、限时购、砍价
- 分销：分销员（导游/民宿主/达人）、二级佣金、提现；🆕 全民营销裂变（普通游客participate的拼团/推荐有礼/裂变海报，与专业分销员角色区分，票付通对标）
- 人群圈选 + 触达（短信、小程序订阅消息）
- 🆕 **声誉/评价管理**：多渠道评价汇聚（小程序内评价、美团/大众点评等外部渠道，需走各平台开放 API）、满意度分析、差评预警与处理闭环（别样红「数据宝」、石基 ReviewPro 对标）

## 12. 渠道中心
- OTA 直连：携程、美团、抖音、飞猪 —— 产品映射、库存价格同步、订单回传、核销状态回传
- B2B 分销 API 开放平台：协议价、授信/预存余额、对账
- 政府「一码游」平台对接
- 🆕 政府码适配层：在「一码游」对接基础上，预留交通码、文博预约码等地方文旅统一码标准的扩展接口（深大智能「文旅一码通」方向，具体接入范围按项目落地）
- 🆕 短视频平台导流：抖音/视频号公域内容引流至小程序，沉淀为会员资产（客如云「引流获客」对标）
- 🆕 **第三方停车系统对接**（2026-06-14 补充，趣买票对标，轻量范围见 ADR-023）：防腐层接收第三方停车系统的计费/通行结果，用于第 3 节停车权益核销核对与分账；不自建车牌识别、道闸控制、独立计费引擎

## 13. 硬件接入平台
- 🆕 **硬件类型与 SN 白名单管理**（2026-06-14 补充）：
  - 硬件类型字典：闸机、PDA、自助机、人脸终端、腕带/手牌读写器、电子价签等，每种类型定义对应的接口权限范围（scope）
  - 设备 SN 码注册：每台物理设备的 SN 码登记后才能获得设备级身份凭证（密钥/证书）
  - 接口鉴权：网关层校验请求携带的设备凭证对应 SN 码是否在白名单内且状态为「已授权」，未注册/已吊销的 SN 码直接拒绝（401/403），防止设备被克隆或第三方仿造终端接入
  - 设备状态机：待激活 → 已授权 → 已吊销/已禁用，支持远程吊销（设备丢失/退役场景）
  - 与第 16 节开放平台 API Key/OAuth2 机制维度不同：API Key 面向「第三方应用」，设备凭证面向「物理终端」，两者统一纳入调用审计
- 设备全生命周期：注册、鉴权、心跳、远程配置、固件 OTA、故障告警
- 多厂商闸机协议适配层；PDA、人脸终端、自助机、酒店自助入住机
- 🆕 温泉/水乐园腕带手牌（RFID）读写设备接入
- 🆕 酒店电子房价牌
- 🆕 餐饮电子菜单、标签打印机、大屏叫号屏（石基 Infrasys 对标）
- 景区边缘节点（本地服务器）：核销/设备管理本地自治 + 云端同步

## 14. 数据中台
- **指标语义层**（metrics layer）：统一口径、维度、血缘 —— AI 报表的底座（见 ADR-012）
- 实时大屏：客流、在园人数、营收、渠道占比
- 经营分析：集团/景区/商户/业态/渠道多维报表
- 财务：结算单、分账明细、佣金报表
- 客流预测、经营诊断
- 🆕 客流热力图、闸机开放数量与人员部署建议报表（趣买票对标，作为运营策略 AI 的数据底座）
- 🆕 餐饮成本/损耗分析报表（与第 10 节供应链数字化对应）
- 🆕 同行竞品情报分析（别样红「数据宝」对标：同行调价、收益榜单对比）—— 二期；数据来源为平台多租户聚合匿名经营数据，按区域+业态+规模分组对标，不爬虫不外采（见 ADR-024），待分组样本量达最小门槛后启动

## 15. AI 能力中心（见 ADR-010 / ADR-012）
- **基础设施**：AI 网关（多模型接入、租户配额计费、敏感数据脱敏）、租户级 RAG 知识库、业务 API 的 MCP/tool-use Agent 接口层
- 🔹 **运营策略 AI**：经营诊断简报、策略建议、异常预警归因；🆕 落地场景示例——闸机调度建议、客流热力分析（趣买票对标）

- 🔹 **营销 AI**：活动策划助手、自然语言圈人群、文案/海报生成、活动自动复盘
- 🔹 **智能客服**：咨询 + 对接订单系统真正办理退改自助
- 🆕 智能核验防假票：核销环节人脸活体检测告警接入 AI 网关（趣买票对标，与第 8 节核销中心联动）
- AI 行程规划、智能定价建议、AI 语音讲解导览（二期）

## 16. 开放平台（见 ADR-011）
- 开发者门户 + API 文档中心（OpenAPI）

- 限流配额、调用计量计费、调用审计
- Webhook 回调（订单/核销等事件，签名验签 + 重试）
- 沙箱环境、API 版本管理
