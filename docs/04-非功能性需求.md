# 04 · 非功能性需求

> 这些是「建设纪律」而非功能项，贯穿所有模块。

## 1. 高并发与性能
- **目标**：支撑重大节假日访问与交易峰值，保障「下单—支付—核销」黄金链路不崩。
- **请求分层消化**：CDN + 静态化（读）→ 多级缓存（本地 + Redis）→ 后端交易核心。
- **交易链路**：网关限流防刷 + 排队机制 → Redis+Lua 原子扣减（热点库存分桶）→ MQ 削峰异步下单 → 分库分表。
- **指标口径需澄清**：「百万级/秒」须区分 PV/QPS 与下单 TPS（成本相差百倍）。详见待确认项。

## 2. 高可用与离线
- **离线核销**为景区生命线：签名票码本地验签 + 景区边缘节点 + 断网续核 + 恢复对账。
- 黄金链路多活、故障降级预案、非核心功能可降级。

## 3. 弹性伸缩（双云 + 私有化）
- K8s（阿里云 ACK / 腾讯云 TKE），应用层统一、基础设施层适配。
- 三层伸缩：HPA（Pod）+ Cluster Autoscaler（节点）+ 节假日定时预扩容。
- Terraform/Helm 基础设施即代码，一套描述参数化输出阿里云/腾讯云/私有化。
- 中间件与对象存储全部抽象，不绑定云厂商专有服务。

## 4. 全链路压测制度
- 节前定期全链路压测，容量规划，预案演练。

## 5. AI 友好工程规范（见 ADR-010）
- 每服务带 `CLAUDE.md` / `AGENTS.md`：职责边界、依赖、本地启动、改动禁区。
- 架构决策记录（ADR）持续维护。
- **契约先行**：OpenAPI 定义所有 API；MQ 事件统一 Schema 注册中心；可由契约生成代码。
- 统一脚手架：所有微服务目录结构/分层/命名/错误码一致，学一个等于学全部。
- 显式优于隐式：少用反射/魔法注解/隐式约定，代码可静态追溯。
- **测试为安全网**：黄金链路高覆盖单测 + 契约测试 + 端到端测试。
- CI 强制：lint/格式化/静态分析/架构守护（ArchUnit 约束分层不被穿透）。
- **一条命令起本地环境**：docker compose 拉依赖 + 种子数据 + Flyway 版本化迁移，支持「改码→起服务→验证」闭环。
- 可观测性：结构化日志、全链路 trace。

## 6. 安全与合规
- 等保三级（尽早测评）。
- 个保法：人脸 / 身份证数据加密存储 + 授权访问 + 最小留存。
- 多租户数据隔离审计。
- 资金存管合规，禁止二清。
- 用户可见文案不暴露内部 key / 内部错误细节。

## 7. 数据治理
- 指标语义层（metrics layer）：统一口径、维度、血缘，作为 AI 报表与经营分析的底座。
- 数据分级分类、敏感数据脱敏（尤其出系统边界给 AI / 第三方时）。
