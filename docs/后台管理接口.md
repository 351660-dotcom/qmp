# 后台管理接口（Admin API）

让平台主数据可由后台维护，替代 Flyway 种子 SQL。所有接口统一前缀 `/admin/v1`，
返回 `ApiResponse`（`{code,message,data,trace_id}`），**必须带 `X-Tenant-Id` 请求头**。

> v1 说明：后台接口暂未接入鉴权/RBAC（ADR-011 开放平台鉴权后续补齐），当前与业务接口同应用、同端口暴露。
> 生产应置于内网/网关后并加管理员鉴权。

## product-service（8081）— 商品 / 票种

| 方法 | 路径 | 入参 | 说明 |
|---|---|---|---|
| POST | `/admin/v1/products` | `{name, description, scenic_id, merchant_id, valid_period_rule, real_name_rule, status?}` | 创建商品，返回 `{product_id}`，status 缺省 DRAFT |
| PATCH | `/admin/v1/products/{id}/status` | `{status}` | 上下架（DRAFT/PENDING_REVIEW/ON_SALE/OFF_SALE） |
| GET | `/admin/v1/products` | - | 商品列表 |
| POST | `/admin/v1/skus` | `{product_id, ticket_type, requires_time_slot, time_slot_definitions[]}` | 创建票种，返回 `{sku_id}` |
| GET | `/admin/v1/skus?product_id=` | - | 票种列表 |

## pricing-service（8082）— 价格

| 方法 | 路径 | 入参 | 说明 |
|---|---|---|---|
| PUT | `/admin/v1/prices` | `{sku_id, sale_date, price_type, price}` | 按 (sku_id,sale_date,price_type) 幂等 upsert；price_type=RETAIL/MEMBER |
| GET | `/admin/v1/prices?sku_id=&sale_date=` | - | 价格列表（sale_date 可选） |

## inventory-service（8084）— 库存桶

| 方法 | 路径 | 入参 | 说明 |
|---|---|---|---|
| POST | `/admin/v1/buckets` | `{sku_id, sale_date, time_slot_id, scenic_id, total_quota, channel_quota?}` | 按 (sku,date,slot) 幂等：存在则调整 total_quota，否则新建；返回 `{bucket_id}` |
| GET | `/admin/v1/buckets?sku_id=&sale_date=&time_slot_id=` | - | 查询库存桶 |

- 调整 `total_quota` 时校验不得小于 `sold+locked`，并删除 Redis 余量 key 使第一道防线按 DB 重置。

## order-service（8087）— 订单

| 方法 | 路径 | 入参 | 说明 |
|---|---|---|---|
| GET | `/admin/v1/orders?status=` | - | 订单列表（按租户，status 可选，最多 200 条） |

## 用后台造一条可下单的数据（示例）

```bash
H='-H X-Tenant-Id:1001 -H Content-Type:application/json'
# 1) 建商品 + 上架
PID=$(curl -s $H -d '{"name":"示例门票","scenic_id":3001,"merchant_id":2001,"real_name_rule":"NONE","status":"ON_SALE"}' \
  http://localhost:8081/admin/v1/products | python3 -c 'import sys,json;print(json.load(sys.stdin)["data"]["product_id"])')
# 2) 建票种
SID=$(curl -s $H -d "{\"product_id\":$PID,\"ticket_type\":\"ADULT\",\"requires_time_slot\":true,\"time_slot_definitions\":[\"09:00-11:00\"]}" \
  http://localhost:8081/admin/v1/skus | python3 -c 'import sys,json;print(json.load(sys.stdin)["data"]["sku_id"])')
# 3) 设价
curl -s -X PUT $H -d "{\"sku_id\":$SID,\"sale_date\":\"2026-08-01\",\"price_type\":\"RETAIL\",\"price\":120.00}" http://localhost:8082/admin/v1/prices
curl -s -X PUT $H -d "{\"sku_id\":$SID,\"sale_date\":\"2026-08-01\",\"price_type\":\"MEMBER\",\"price\":99.00}" http://localhost:8082/admin/v1/prices
# 4) 配库存
curl -s $H -d "{\"sku_id\":$SID,\"sale_date\":\"2026-08-01\",\"time_slot_id\":1,\"scenic_id\":3001,\"total_quota\":500}" http://localhost:8084/admin/v1/buckets
# 之后即可走 C 端 POST /api/v1/orders 下单
```
