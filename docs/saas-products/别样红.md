# 别样红核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：围绕别样红云 PMS/美团酒店管理系统，整理酒店 SaaS 可对标功能清单。  
> 确认口径：公开页面明确出现的功能标为 `公开可确认`，版本差异和套餐差异统一列入待确认。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 别样红云 PMS / 美团酒店管理系统 | 酒店前台、房态、订单、账务、客房、营销一体化系统 | 公开可确认 |
| 微 PMS / App | 手机端远程管店、审批、数据查看 | 公开可确认 |
| 数据宝 | 经营数据、同行动态、收益分析、流量转化分析 | 公开可确认 |
| 酒店数字营销 | 微订房、微商城、会员、分销、券营销 | 公开可确认 |
| 智能收银/聚合支付 | 美团官方聚合支付、押金和账务联动 | 公开可确认 |
| 智慧硬件/场景 | 门锁、身份证识别、自助入住、语音客控、电竞房等 | 部分公开 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| 精英商务版、领航营销版、至尊旗舰版功能差异 | 公开功能可能分套餐 |
| 是否支持美团以外 OTA 直连 | 决定是否适合多平台经营酒店 |
| 微订房、会员储值、券营销、数据宝是否额外收费 | 直接影响预算 |
| 智能门锁、自助机、语音客控、电竞房兼容品牌 | 影响硬件采购 |
| 数据导出、历史数据迁移和合同退出机制 | PMS 替换成本高，必须确认 |
| 财务对账是否能覆盖支付、OTA 佣金、退款、发票 | 财务闭环关键 |
| 连锁集团权限、报表和价格管控颗粒度 | 连锁酒店选型关键 |
