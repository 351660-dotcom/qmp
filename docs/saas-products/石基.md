# 石基核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：围绕石基酒店 SaaS、Daylight PMS、Infrasys Cloud POS 及相关平台能力，整理可对标功能清单。  
> 注意：石基产品线很广，本文重点放在酒店和餐饮 SaaS 核心产品，不展开零售、采购、人力、财务等全部集团产品。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| Daylight PMS / Shiji Enterprise Platform | 云 PMS、集团多物业、单一客史、开放 API | 公开可确认 |
| Infrasys Cloud POS | 酒店和连锁餐饮云 POS、移动点单、扫码支付、厨房协同 | 公开可确认 |
| ReviewPro | 宾客满意度、声誉和评价管理 | 公开可确认 |
| IcePortal | 酒店内容分发管理 | 公开可确认 |
| 分销解决方案 | 酒店分销、渠道和内容连接 | 部分公开 |
| 支付解决方案 | 酒店与餐饮支付接入 | 部分公开 |
| 采购/成本/财务/HR 等 | 酒店集团后台管理套件 | 部分公开 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| Daylight PMS 在中国区可售版本、部署区域和数据存储位置 | 石基国际化产品涉及区域和合规边界 |
| Daylight、原西软、Cambridge、SEP 等产品线关系 | 防止选错产品线 |
| API 端点实际开放范围、费用和认证方式 | 影响二次开发和集成成本 |
| Infrasys 在中国本地支付、发票、外卖平台接口 | 餐饮落地关键 |
| PMS 与 POS、ReviewPro、IcePortal、支付、分销之间是否原生打通 | 影响整体方案复杂度 |
| 报价维度：酒店数、房间数、模块、接口、交易量、实施服务 | 影响预算 |
| 审计日志、数据导出、备份和退出机制 | 大型集团必须确认 |
