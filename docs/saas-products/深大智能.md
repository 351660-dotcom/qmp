# 深大智能核心 SaaS/智慧文旅产品功能清单

> 更新日期：2026-06-13  
> 整理目标：把深大智能公开资料中可见的智慧文旅、智游宝、一码通和数字营销能力拆成产品功能清单。  
> 注意：深大智能更偏“文旅数字化综合解决方案商”，其中不少能力可能以项目制、私有化或区域平台形式交付，不一定都是标准 SaaS。

## 1. 核心 SaaS/平台产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 智游宝公众服务支撑平台 | 电子票务、分销、发码、验码、结算、资源渠道连接 | 公开可确认 |
| 智慧景区系统 | 景区售检票、电子门票、软硬件集成和景区管理 | 部分公开 |
| 文旅一码通/统一码平台 | 多码归一、景区入园、交通、文博预约等场景统一通行 | 部分公开 |
| 区域旅游电商/LOTS 平台 | 旅游目的地资源整合、交易和运营平台 | 部分公开 |
| 旅游大数据平台 | 文旅数据汇聚、分析、监管和运营决策 | 部分公开 |
| 数字营销平台 | 资源方、运营商、中小代理商自建营销平台 | 部分公开 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| 哪些是标准 SaaS，哪些是项目制交付 | 深大智能公开能力偏综合方案，不一定都是标准产品 |
| 智游宝与深大智能其他平台的数据关系 | 影响系统边界、账号体系和数据统一 |
| 文旅一码通是否可单独采购或只作为城市级项目交付 | 影响采购路径 |
| 景区售检票、预约、实名制、客流承载是否标准化 | 单景区落地关键 |
| 当前 OTA、支付、硬件和政务平台接口清单 | 影响实施周期 |
| 私有化、政务云、信创、等保支持情况 | ToG/国企项目通常必问 |
| 大数据平台的指标口径、数据源和报表清单 | 避免只有大屏展示、缺运营深度 |
