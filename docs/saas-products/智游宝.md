# 智游宝核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：将智游宝公开资料中的平台能力拆成可对标的功能清单。  
> 确认口径：`公开可确认` 表示官网、教程或应用商店明确出现；`部分公开` 表示方向明确但功能边界不完整；`需商务确认` 表示公开资料不足。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 智游宝电子票务平台 | 景区、旅游资源方和分销商之间的电子票交易、发码、验码平台 | 公开可确认 |
| 供应商后台 | 面向景区/资源方的产品、订单、财务、检票和分销管理 | 公开可确认 |
| 分销商后台 | 面向渠道商/旅行社的销售、订单、财务、报账和开放平台能力 | 公开可确认 |
| 代理商后台 | 面向代理商的销售、订单、财务和分销报表管理 | 公开可确认 |
| 智游宝 App | 快速检票、票务预订等移动端能力 | 公开可确认 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| 当前后台是否仍按供应商/分销商/代理商三端提供 | 公开教程可能较早，需确认现行版本 |
| 标准 SaaS 是否包含硬件、闸机、自助机和手持机 | 影响总价和交付周期 |
| 是否支持分时预约、实名制、团队票、年卡、二消核销 | 当前景区票务常见刚需 |
| 开放平台 API 清单、调用限制和收费 | 影响自研系统或第三方系统接入 |
| 淘宝以外的携程、美团、抖音、飞猪等渠道支持情况 | 渠道生态已变化，需确认新版接口 |
| 财务结算资金流是否经过智游宝 | 涉及资金安全和合同责任 |
| 数据导出、备份、迁移、审计日志 | 影响长期可控性 |
