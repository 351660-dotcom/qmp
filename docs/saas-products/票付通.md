# 票付通核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：从公开资料中提取“可对标、可勾选”的 SaaS 功能项。  
> 确认口径：`公开可确认` 表示公开产品页明确出现；`部分公开` 表示公开资料出现方向但未给完整功能边界；`需商务确认` 表示属于该场景常见能力，但公开资料不足以确认是否标准交付。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 票务上云 | 景区、剧场、温泉、乐园等业态的云售检票系统 | 公开可确认 |
| 渠道分销 | OTA、同业、旅行社、导游/司机、门店等渠道分销管理 | 公开可确认 |
| 数智营销 | 小程序商城、优惠券、拼团、砍价、返利等营销工具 | 公开可确认 |
| 智能设备 | 闸机、自助机、手持机、云票务终端等售检票硬件 | 公开可确认 |
| 全域旅游/综合管控 | 区域文旅资源、运营、数据和指挥管理 | 部分公开 |
| 数据要素/大数据 | 销售、渠道、客源、经营分析等数据能力 | 部分公开 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| 标准 SaaS、私有化、项目定制分别包含哪些模块 | 公开资料产品线很全，但不等于标准版全部包含 |
| 分时预约、实名制、最大承载量管控是否为标准功能 | 景区合规和节假日客流管理关键 |
| OTA/API 接口清单和收费方式 | 直接影响接入成本和上线周期 |
| 离线售检票数据同步机制 | 高峰期网络不稳时影响入园效率 |
| 财务清分是否涉及资金托管或支付服务商 | 涉及资金安全、合同和合规责任 |
| 闸机、自助机、手持机是否自研及售后 SLA | 影响故障响应和维护成本 |
| 数据导出、备份、迁移能力 | 避免后续被系统锁定 |
