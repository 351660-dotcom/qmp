# 绿云核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：把绿云面向大住宿业的核心 SaaS 产品拆成酒店 PMS/CRS/CRM/POS/智慧住/数据平台等功能清单。  
> 确认口径：绿云公开资料部分为动态页面，以下以可公开交叉确认的信息为主。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 绿云 PMS / iHotel | 酒店前台、房态、预订、账务等核心管理 | 公开可确认 |
| CRS 中央预订 | 酒店集团中央预订、库存和渠道协同 | 部分公开 |
| CRM/会员 | 会员、客户关系、私域运营 | 部分公开 |
| POS/餐饮 POS | 酒店餐饮点单、结账、房账协同 | 部分公开 |
| 智慧住 | 自助入住、在线选房、住中服务、客控等住客体验方案 | 公开可确认 |
| 数据平台 | 订单、支付、渠道、会员等经营数据汇聚分析 | 部分公开 |
| 电商平台 | 酒店私域电商、会员营销、全渠道交易 | 部分公开 |
| Oracle Hospitality 相关产品 | Opera PMS、Simphony 等高星/集团酒店产品实施与服务 | 公开可确认 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| PMS、iHotel、MiHotel、iRoom、智慧住之间的边界 | 防止采购时重复或漏买模块 |
| CRS、CRM、POS、数据平台是否包含在基础 PMS 中 | 直接影响报价 |
| 支持哪些 OTA、支付、公安、门锁、客控、发票接口 | 影响上线周期 |
| 集团版的多品牌、多区域、多门店权限能力 | 酒店集团选型关键 |
| 数据平台具体报表和指标清单 | 区分“有数据”与“能经营分析” |
| 数据导出、备份、迁移和合同退出 | 长期可控性关键 |
| Oracle Hospitality 与绿云自研产品的销售边界 | 高星酒店/集团选型需明确 |
