# 哗啦啦核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：围绕哗啦啦餐饮 SaaS 的门店经营、线上经营、供应链、财务和数据能力，整理可对标功能清单。  
> 注意：本次未抓取到稳定完整的官网产品清单，以下以公开第三方资料和公开案例整理，落地选型必须向官方确认当前版本。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 门店经营 SaaS | 餐饮门店收银、点餐、排队、预订、后厨、报表 | 部分公开 |
| 线上经营 SaaS | 线上餐厅、会员营销、私域运营、外卖/团购协同 | 部分公开 |
| 供应链系统 | 采购、订货、仓配、中央厨房、门店供应链协同 | 部分公开 |
| 财务/支付 | 支付收单、财务报表、清结算相关能力 | 部分公开 |
| 大数据/老板通 | 经营分析、成本分析、营收分析、运营建议 | 部分公开 |
| 22CITY/中央厨房相关 | 城市共享中央厨房、食品研发加工、冷链配送 | 部分公开 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| 当前官方产品套餐和功能模块清单 | 公开第三方资料不够完整 |
| 是否可只采购 SaaS 软件，不使用其资金清算服务 | 降低资金风险 |
| 支付资金流、提现周期、清算主体和异常赔付 | 公开舆情后必须重点核查 |
| 外卖、团购、抖音、小程序、企业微信接口范围 | 决定线上经营能力 |
| 供应链模块是否软件化交付，还是包含履约服务 | 影响成本和责任边界 |
| 连锁总部权限、菜品、价格、活动和报表管控颗粒度 | 中大型餐饮选型关键 |
| 数据导出、迁移和合同退出机制 | 避免系统锁定 |
