## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| 硬件型号、软件套餐、年费和服务费 | 客如云常见软硬件一起采购 |
| 美团、饿了么、抖音、微信、支付宝等接口范围 | 决定外卖团购和公域获客能力 |
| 会员营销、供应链、AI 智能体是否基础版包含 | 防止功能看得到但用不了 |
| 弱网/断网收银和数据补传机制 | 门店稳定经营关键 |
| 连锁总部的价格、菜品、活动、权限管控颗粒度 | 连锁品牌选型关键 |
| 支付费率、分账费率和到账周期 | 影响长期成本 |
| 数据导出和系统迁移能力 | 避免后续被锁定 |
