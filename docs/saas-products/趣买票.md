# 趣买票核心 SaaS 产品功能清单

> 更新日期：2026-06-13  
> 整理目标：围绕趣买票智慧票务 SaaS，把公开资料中的票务、售票、检票、渠道、营销、硬件和数据能力拆成可对标功能清单。  
> 注意：趣买票公开内容中有较多榜单和宣传型文章，本文对宣传性 AI 能力单独标注为需确认。

## 1. 核心 SaaS 产品

| 产品/能力 | 功能定位 | 确认程度 |
|---|---|---|
| 智慧票务系统 | 景区、乐园、剧院等场景的售票、检票、订单、库存管理 | 公开可确认 |
| 购票小程序 | 游客线上购票、订单查询、营销触达 | 部分公开 |

| 酒店/零售/游乐/剧院系统 | 多业态文旅经营扩展 | 部分公开 |

## 3. 重点需向厂商确认

| 确认项 | 为什么重要 |
|---|---|
| AI 核验、动态定价、热力图、智能客服是否标准模块 | 公开资料偏宣传，需防止过度期待 |
| 标准 SaaS、私有化、定制项目功能差异 | 决定预算和交付周期 |
| 分时预约、实名制、团队票、年卡、二消核销能力 | 景区核心刚需 |
| OTA、支付、闸机、自助机、手持机接口和设备清单 | 影响上线与售后 |
| 离线核销和高峰并发能力 | 节假日入园稳定性关键 |
| 多业态系统是否真实一体化，还是多个独立模块 | 影响数据统一和运营效率 |
| 数据导出、备份、迁移和售后 SLA | 长期可控性关键 |
