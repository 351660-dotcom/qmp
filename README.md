# 景区文旅 SaaS 平台

面向**多文旅集团、多景区、多商户**的景区领域 SaaS 系统。支持门票、酒店、餐饮、零售、游乐、剧院、游船等多业态；具备高并发、离线核销、聚合支付与分账、硬件集成（闸机/PDA/自助机）、AI 原生、API-First 开放平台等能力。

> 当前阶段：**门票全链路领域模型/服务契约/数据库设计已完成**，进入工程脚手架落地阶段。
